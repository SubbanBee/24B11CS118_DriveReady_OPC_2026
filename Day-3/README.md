# Day 3 - Your First AI Agent

## Objective
Learn the basics of AI Agents and build a Sweet Crumbs Home Bakery assistant using LangChain and Groq.

## Concepts Covered
- Chatbot vs AI Agent
- Four components of an AI Agent
- Agent loop: Think, Act, Observe, Repeat
- LangChain basics
- Chat models and Prompt Templates
- Chains and Conversation Memory
- Automated Testing
- Temperature Experiment

## Practical Tasks
1. Connected LangChain with Groq.
2. Created a Sweet Crumbs assistant.
3. Implemented conversation memory.
4. Created tests.csv with 10 customer questions.
5. Achieved 10/10 in initial automated tests.
6. Compared different prompts and temperatures.
7. Created an Agent preview.
8. Classified AI tasks.
9. Created Python functions for cake price and eggless availability.
