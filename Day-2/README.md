
# Day 2 - Sweet Crumbs AI

## Objective
To understand prompts, conversation memory, Python functions, decorators, error handling, and JSON through a bakery chatbot.

## Tools Used
- Python
- Google Colab
- Groq API
- OpenAI Python Library
- GPT-OSS-20B

## Tasks Completed
1. Understanding Messages and Roles
2. System Prompt - Role, Facts, Rules and Format
3. Few-Shot Examples
4. JSON Output
5. Conversation Memory
6. Python Dictionaries and JSON
7. Functions and Type Hints
8. Decorators
9. Try/Except Error Handling
10. Sweet Crumbs AI Chatbot

## Final Project
Built a Sweet Crumbs Home Bakery chatbot that:
- Answers cake price questions.
- Remembers customer conversation details.
- Uses business information to answer questions.
- Calculates order totals.
- Generates customer order details in JSON.
- Handles invalid quantities.

## Business Catalogue
- Chocolate Cake: Rs. 650
- Plum Cake: Rs. 500
- Eggless cakes: Available

## Key Learnings
- How system, user and assistant messages work.
- How prompts guide AI responses.
- How conversation history provides memory.
- How Python functions and decorators work.
- How JSON stores structured data.
- How try/except handles errors.
